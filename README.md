This project is coded in C++ and is programmed to mimic playing the card game WAR. In WAR, two cards from the deck are pulled at random and the numbers are ranked against each other with the bigger number winning. The program assigns a suit and rank to each figurative card and has a number of functions implemented including the shuffling of the cards within the deck. In the end, we are also able to see the final stats of the games played as well.
